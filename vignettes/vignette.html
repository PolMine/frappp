The workflow to generate XML

In this vignette, we show how to generate an XML document of a plenary protocol. The example chosen is a verbatim record of a short session in UN General Assembly. Due to the structural similarity of all kinds of plenary protocols (including the verbatim records of UN bodies), this example may illustrate the workflow for parsing plenary protocols using .

The parser of the package, i.e. the class is designed to process plain text documents. However, the usual scenario is that the protocol to be processed is available as a pdf document. In order to walk through the steps we usually encounter, we start with turning a pdf document into plain text.

Preparing a plain text file

There is a set of R packages to extract text from pdf documents, namely Rpoppler and pdftools. However, a typical issue with the pdf of plenary protocols is that documents have a two-column layout. To deal with this special kind of situation, we have developed the package . It is not yet available at CRAN, but it can be installed in convenient manner from the GitHub presence of the PolMine Project using the installation mechanism offered by the package.

if (!"trickypdf" %in% installed.packages()[,"Package"]){

}

The package includes some pdf documents serving as example. The document we will process is the first meeting of the 2016 UN General Assemply (A/71/PV.1). In interactive R session, have a look at the document, and consider two-column layout.

doc <- system.file(package = "trickypdf", "extdata", "pdf", "UN_GeneralAssembly_2016.pdf")
if (interactive()) browseURL(doc)

With other approaches for processing pdf, you would extract the text from the pdf document and have to invest some time to get rid of anything on the margins of the pdf document as a post-processing step. The package allows you to define in advance the boxes with relevant information. The package documentation explains in more detail how you would do that. In our case, the following commands will get us the plain text out of the protocol of the General Assembly.

UN <- trickypdf::PDF$new(filename_pdf = doc)
UN$add_box(page = 1, box = c(top = 232, height = 400, left = 52, width = 255))
UN$add_box(page = 1, box = c(top = 232, height = 400, left = 303, width = 255), replace = FALSE)
UN$add_box(page = 2, box = c(top = 80, height = 595, left = 52, width = 255))
UN$add_box(page = 2, box = c(top = 80, height = 595, left = 303, width = 255), replace = FALSE)
UN$get_text_from_boxes(paragraphs = FALSE)
plaintext <- unname(unlist(UN$pages))

The takes text files as input. So we save the document to a temporary file.

undoc_tmp <- tempfile()
writeLines(text = plaintext, con = undoc_tmp)

The class that implements the workflow to process a plenary protocol is the class. It is a class of the R6 class system. The notation of using R6 classes may be somewhat uncommon for many R users. Usually you will know the S3 and the S4 class system. To learn more about R6 classes, consult the vignette of the R6 package, the introduction to the different class systems in Hadley Wickham’s Advanced R Website is an excellent entry to understand the notion of reference classes.

Compared to R’s built-in reference classes (RefClass), R6 is somewhat more efficient. But in fact the biggest advantage of R6 is that you can include classes inheriting from the class in other packages than . Inheritance is possible across packages. So let us instantiate our parser for the General Assembly verbatim record.

UNGAParser <- PlenaryProtocolParser$new()

Processing the document requires two steps. First, we have to configure the the parser. This means that we supply a set of regular expressions to detect speakers, agenda items and instructions from the stage. Second, we process the individual document.

Configuring the parser

Defining regular expessions to detect speakers

UNGAParser$speakerRegex <- list(
  
  pres = list(
    regex = "^(The\\s+President):\\s*(.+)$",
    fn = function(who, txt){
      c(
        who = who,
        state = "NA",
        role = "presidency",
        position = "presidency",
        text = txt
      )
    }
  ),
  
  sg = list(
    regex = "^(The\\sSecretary-General):\\s*(.+)$",
    fn = function(who, txt){
      c(
        who = who,
        state = "NA",
        role = "secretary-general",
        position = "secretary-general",
        text = txt
      )
    }
  )
  
)

UNGAParser$speakerMismatch <- character()

Define regular expressions to detect calls for agenda items

UNGAParser$agendaItemRegex <- c(any = "^Item\\s+\\d+\\sof.*agenda.*$")
UNGAParser$agendaItemTypes <- c(any = "debate")

Define regular expressions to detect stage instructions

UNGAParser$stageRegex <- c(
  end_of_session = "^\\s*The\\s+meeting\\s+rose\\s+at\\s+\\d+\\s[ap]\\.m\\.\\s*$"
)

Processing a Protocol

UNGAParser$readFile(filename = undoc_tmp, id = "A/71/PV.1")
UNGAParser$metadata <- list(
  legislativePeriod = "71", # formally, sessions are not called legislative periods at the UN
  sessionNo = "1",
  date = "2016-09-03",
  birthday = as.character(Sys.Date()),
  package = "frappp",
  version = packageVersion("frappp"),
  retrievalDate = "unknown",
  filetype = "pdf",
  url = "http://www.un.org/en/ga/",
  publisher = "United Nations",
  title = "Verbatim Records of the United Nations"
  )
UNGAParser$preprocessing() # remove leading and and trailing spaces
